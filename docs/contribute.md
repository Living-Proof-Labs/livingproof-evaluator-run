# Contribute

Open an [issue](https://github.com/Living-Proof-Labs/livingproof-evaluator-run/issues)
for questions or proposed behavior, or a
[pull request](https://github.com/Living-Proof-Labs/livingproof-evaluator-run/pulls)
for a focused change. Keep authored documentation in `docs/` and the README summary
in `README.md`. Generated pages and downloaded branding are not committed.

This documentation adopts the
[documentation recipe at guidelines v7.10.9](https://github.com/Living-Proof-Labs/collaboration-guidelines/blob/v7.10.9/docs/documentation-recipe.md)
(commit `c5fa9d9794d0ebd289f51b247fe7872de0db9c27`) and its shared brand.
See [verification](verification.md) for the build and local exceptions.
Independent review follows the
[pinned review procedure](https://github.com/Living-Proof-Labs/collaboration-guidelines/blob/v7.10.9/docs/independent-review.md).

## Reporting limits

No security reporting policy is established in this repository. Public issues
are for non-sensitive questions; do not post secrets or vulnerabilities there.
A private reporting route remains an adoption gap.
